Política de Privacidade

Última atualização: 18 de outubro de 2026 · English version below

Quem somos

Alpha Room Analytics é uma ferramenta de uso pessoal de Ricardo Carvalho, CFP®, criador do canal The Alpha Room no YouTube. Ela não é oferecida ao público: o único usuário é o próprio Ricardo.

Quais dados acessamos

  • YouTube (somente leitura): métricas do canal do próprio Ricardo, como visualizações, tempo assistido, retenção, inscritos e fontes de tráfego, pelas APIs YouTube Data, YouTube Analytics e YouTube Reporting.
  • Dados públicos: estatísticas públicas de canais de referência no YouTube (inscritos, vídeos e visualizações), as mesmas que qualquer pessoa vê no site do YouTube.
  • Google Slides e Google Drive: a ferramenta cria e edita apenas os arquivos que ela mesma gera (o relatório semanal e imagens de gráfico temporárias). Ela não lê outros arquivos do Drive.

Como usamos os dados

Os dados são usados exclusivamente para gerar um relatório semanal de desempenho do canal, salvo no Google Drive do próprio Ricardo. Não há outros usos.

Armazenamento

Os dados ficam no computador do Ricardo e no Google Drive dele. As credenciais de acesso ficam salvas apenas nesse computador.

Compartilhamento

Não vendemos, compartilhamos nem transferimos dados para terceiros. Não usamos os dados para publicidade.

Uso das APIs do Google

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Privacy Policy (English)

Last updated: October 18, 2026

Who we are. Alpha Room Analytics is a personal tool used by Ricardo Carvalho, CFP®, creator of the YouTube channel The Alpha Room. It is not offered to the public; Ricardo is its only user.

Data we access. (1) YouTube, read-only: metrics for Ricardo's own channel (views, watch time, retention, subscribers, traffic sources) via the YouTube Data, YouTube Analytics and YouTube Reporting APIs. (2) Public data: public statistics of benchmark YouTube channels, the same anyone can see on youtube.com. (3) Google Slides and Google Drive: the tool only creates and edits the files it generates itself (the weekly report and temporary chart images). It does not read any other Drive files.

How we use data. Only to generate a weekly channel performance report saved in Ricardo's own Google Drive.

Storage. Data stays on Ricardo's computer and in his Google Drive. Access credentials are stored only on that computer.

Sharing. We do not sell, share or transfer data to third parties, and do not use it for advertising.

Google API data. Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.
